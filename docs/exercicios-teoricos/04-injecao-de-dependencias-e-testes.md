# Pergunta 4 — Injeção de dependências e testes

## Pergunta

O que é injeção de dependências e como ela facilita a escrita de testes automatizados?

## Resposta

Injeção de dependências é quando uma classe **recebe de fora** aquilo que precisa para funcionar, em vez de criar suas próprias dependências. Isso facilita os testes porque podemos utilizar versões falsas dos repositórios, sem precisar conectar a um banco de dados real.
